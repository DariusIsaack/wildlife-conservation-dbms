# Wildlife Conservation Monitoring Database Management System

A web-based wildlife conservation management system developed using Flask, PostgreSQL, HTML, CSS, JavaScript, and Supabase.

## Features

- User authentication
- Animal management CRUD
- Habitat management CRUD
- Observation management
- Reports and analytics
- SQL queries and PL/SQL functions
- Chart visualizations

## Technologies Used

- Python Flask
- PostgreSQL
- Supabase
- HTML/CSS/JavaScript
- Chart.js
